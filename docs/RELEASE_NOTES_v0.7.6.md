Hearth is now Inglen. Updating keeps your chats, memory, models, folders and settings where they were, and an older install keeps the assistant's name and folder it already had.

Inglen is a desktop AI that lets any model use your PC's apps for you. v0.7.6 lets Claude Code, Codex, Cursor, OpenCode and other agents be the brain on the plan you already pay for, all answering to one approval switch that decides what runs without asking. You can watch it work the desktop, with an edge round the screen and its own pointer. Inglen Plus adds a phone app where you follow each step, allow or deny risky ones, talk to it on a call, and get a call back when something needs you. Voice mode handles being talked over on speakers and now speaks and understands Hindi. Memory keeps track of where each chat stands and searches past chats by time. Pictures and short videos are made on your own graphics card. Saved keys are sealed, outside content can't quietly send your data anywhere, and every file change can be undone. The window has new looks, a quieter new chat, an eight-step setup and a Files tab, and the terminal streams replies with arrow-key pickers.

The full list is in [CHANGELOG.md](https://github.com/0pen-Sourcer/Hearth/blob/main/CHANGELOG.md), and how each part works is in [docs/RELEASE_NOTES_v0.7.6.md](https://github.com/0pen-Sourcer/Hearth/blob/main/docs/RELEASE_NOTES_v0.7.6.md).

On v0.7.2 or newer, Inglen updates itself without a reinstall. On v0.7.0 or v0.7.1, run the installer once.

## Downloads

- **Full**, `Hearth-Setup-v0.7.6-preview.exe` (about 1.7 GB), includes the local engine, so a model runs on your PC with nothing else installed.
- **Lite**, `Hearth-Setup-Lite-v0.7.6-preview.exe` (about 650 MB), uses LM Studio, Ollama or a cloud key you already have.

Both install to your user folder without admin rights. Each installer is signed with Inglen's release key, and the in-app updater refuses one whose signature doesn't match. They are not Authenticode-signed yet, so Windows may still show the unknown-publisher box on a first install; choose More info, then Run anyway. Linux and macOS run from source.
